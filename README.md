# Crystal Sort: Mine Lab

Публичная WebGL-сборка игры-головоломки Unity «Глубины Авроры».

- 24 последовательных уровня с чистым тестовым стартом и картой экспедиции.
- Портретная оболочка 9:16 для телефона и настольного браузера.
- Версионный кэш WebGL-файлов, чтобы повторный запуск не скачивал сборку заново.
- Для сетевого сбоя предусмотрена кнопка «Повторить загрузку».
- В настройках доступны звук, музыка, вибрация, язык, возврат к карте и закрытие.

Актуальная страница: https://ignatov04.github.io/crystal-sort-game/?v=783&fresh=1

Rewarded video в WebGL-проверке отключён провайдером; кнопка открывает условия просмотра без фиктивной награды.
