# Crystal Sort: Mine Lab

Публичная тестовая WebGL-сборка игры-головоломки Unity «Глубины Авроры» (v781).

- 24 последовательных уровня в четырёх секторах карты экспедиции.
- Чистый первый запуск для тестирования доступен по ссылке с параметром `fresh=1`; прогресс сохраняется локально после старта.
- Управление: выберите исходную колбу, затем колбу назначения.
- В настройках доступны закрытие окна, возврат к карте, звук, музыка, вибрация, язык и сведения об игре.
- Три усилителя получают по 3 стартовых заряда; при нуле показывается значок видео с плюсом и открываются условия добровольного просмотра. Фактическая выдача рекламной награды в WebGL недоступна: рекламный сервис отключён.
- Сборка рассчитана на GitHub Pages и использует портретную оболочку 9:16 с фиксацией по visual viewport для мобильных браузеров.
- Фон карты собран от морского дна к поверхности: платформа снизу, голубая вода сверху, плавные перекрытия между частями без пустых полос. Линия маршрута скрывается только у самой карточки уровня.

Тестовая ссылка первого запуска:
https://ignatov04.github.io/crystal-sort-game/?v=781&fresh=1

Сведения о Unity/WebGL-сборке находятся в `build-manifest.json` (Unity 6.3 LTS, portrait 1080×1920).
