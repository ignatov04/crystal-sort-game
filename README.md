# Crystal Sort: Mine Lab

Актуальная публичная WebGL-сборка игры-головоломки Unity «Глубины Авроры» (v775).

- 24 последовательных уровня в четырёх секторах карты экспедиции.
- Чистый первый запуск для тестирования доступен по ссылке с параметром `fresh=1`; прогресс сохраняется локально после старта.
- Управление: выберите исходную колбу, затем колбу назначения.
- В настройках доступны повтор уровня, звук, музыка, вибрация и язык.
- Три усилителя получают по 3 стартовых заряда; при нуле показывается CTA «СМОТРЕТЬ». Фактическая выдача rewarded-рекламы в WebGL помечена DATA_GAP, так как LevelPlay отключён.
- Сборка рассчитана на GitHub Pages и использует портретную оболочку 9:16 с фиксацией по visual viewport для мобильных браузеров.

Тестовая ссылка первого запуска:
https://ignatov04.github.io/crystal-sort-game/?v=775&fresh=1

Сведения о Unity/WebGL-сборке находятся в `build-manifest.json` (Unity 6.3 LTS, portrait 1080×1920).
