# Crystal Sort: Mine Lab

Публичная WebGL-сборка игры-головоломки Unity **«Глубины Авроры»**.

- 24 последовательных уровня с картой экспедиции и локальным прогрессом.
- Управление: выберите исходную колбу, затем колбу назначения.
- В настройках доступны повтор уровня, звук, музыка, вибрация и язык.
- Сборка рассчитана на GitHub Pages и использует портретную оболочку 9:16,
  чтобы интерфейс не обрезался в настольном браузере.

Откройте `index.html` на опубликованной странице проекта:
https://ignatov04.github.io/crystal-sort-game/

Сведения о Unity/WebGL-сборке находятся в `build-manifest.json`.
